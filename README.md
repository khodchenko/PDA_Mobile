# ПДА для S.T.A.L.K.E.R. Anomaly / GAMMA на телефоне

Телефон показывает данные из игры: уровень, координаты, время, здоровье,
радиацию, деньги и карту с пройденным маршрутом. Свой мост с нуля, без
закрытого REAL PDA / MUZZPAD. Почему так — в `REAL_PDA_GAMMA_ANALYSIS.md`,
план работ — в `PLAN.md`.

Цель: Anomaly 1.5.3 и сборка GAMMA 0.9.5.

```
игра (Lua-аддон) ──► pda_fast.json / pda_slow.json ──► мост на ПК ──► HTTP + SSE по Wi-Fi ──► браузер телефона
```

Сокетов в Lua-движке Monolith нет, поэтому игра пишет снапшоты в файлы, а мост
их читает. `os.rename` тоже нет, поэтому атомарной записи нет: каждый файл
обрамлён `seq` … `seq_end`, и мост отбрасывает недописанные снапшоты.

## Что готово сейчас

| Часть | Где | Что делает |
| --- | --- | --- |
| Протокол v1 | `protocol/` | JSON Schema снапшотов и примеры |
| Игровой аддон | `addon/stalker_pda/` | Lua-экспортёр для MO2: уровень, позиция, направление, время, здоровье, радиация, имя, деньги |
| Мост | `bridge/` | Python 3.10+ без зависимостей: чтение файлов, токен, `/api/state`, SSE `/api/stream`, раздача веба |
| Веб-ПДА | `web/` | Vite + React + Tailwind + shadcn/ui: Статус, Карта, Связь, Ещё |

Аддон проверен под LuaJIT на заглушках движка, **в настоящей игре ещё не
запускался**. Установка в GAMMA и что прислать после первого запуска —
`README_GAMMA.md`. Какие вызовы движка используются — `GAMMA_COMPATIBILITY.md`.

Без игры мост запускается с демо-генератором, который пишет такие же файлы,
как аддон: переходы между уровнями, загрузки, смерть и новая сессия,
радиационные пятна, 1% недописанных файлов.

На вкладке «Связь» видна вся цепочка игра → аддон → мост → телефон: где
именно оборвалось, возраст снапшотов, отброшенные файлы и журнал событий.

## Запуск демо

Нужны Python 3.10+ и Node.js 20+.

```bash
cd web && npm install && npm run build && cd ..
cd bridge && python3 -m pda_bridge --demo
```

Мост поднимется на порту 47615 и напечатает адреса. На этом же ПК откройте
`http://127.0.0.1:47615`: страница привяжется сама.

### Телефон

1. Телефон и ПК в одной Wi-Fi сети.
2. На ПК откройте `http://127.0.0.1:47615` → вкладка «Связь» → QR-код.
3. Отсканируйте QR телефоном. Ссылка содержит токен, он сохранится в браузере.
4. В Chrome: меню → «Добавить на главный экран».

Если телефон не подключается — разрешите входящие на TCP 47615 в брандмауэре
Windows (при первом запуске Windows обычно спрашивает сам).

Токен лежит в `bridge/.data/token`. Новый токен (старые телефоны отвяжутся):
`python3 -m pda_bridge --demo --reset-token`.

## Режимы моста

```bash
python3 -m pda_bridge --demo                     # демо-игра
python3 -m pda_bridge --snapshot-dir ПАПКА        # читать файлы настоящей игры
python3 -m pda_bridge --locate ИГРА MO2          # найти, куда игра пишет снимки
python3 -m pda_bridge --demo --record run.jsonl  # записать поток снапшотов
python3 -m pda_bridge --replay run.jsonl         # проиграть запись по кругу
python3 -m pda_bridge --demo --torn-rate 0.2     # больше недописанных файлов
python3 -m pda_bridge --port 47615 -v            # порт, подробный лог
```

Лог моста: `bridge/.data/bridge.log`.

## Разработка

```bash
cd bridge && python3 -m pda_bridge --demo   # терминал 1
cd web && npm run dev                       # терминал 2, http://127.0.0.1:47616
```

Dev-сервер Vite проксирует `/api` на мост (`PDA_BRIDGE_URL`, по умолчанию
`http://127.0.0.1:47615`).

Проверки:

```bash
cd bridge && python3 -m unittest discover -s tests
python3 addon/tests/test_exporter.py           # нужен luajit
cd web && npm test && npm run typecheck && npm run lint
python3 tools/pack_addon.py                    # zip аддона для MO2 в dist/
```

## Ограничения

- Связь по обычному http в локальной сети. Ярлык на главном экране — это
  закладка, а не полноценное PWA (для него нужен https).
- Текстуры карт, задания, инвентарь, контакты и сообщения пока не читаются.
  Интерфейс показывает их как недоступные, а не пустые.
- Мост должен работать на ПК постоянно, поэтому на хостинг проект не
  выкладывается.
