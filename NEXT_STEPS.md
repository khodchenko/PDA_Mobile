# Что нужно сделать владельцу проекта

Код аддона проверен только вне игры. Дальше нужен запуск на вашей установке.

## 1. Первый запуск аддона в игре

Подробно: `README_GAMMA.md`.

1. Собрать архив: `python3 tools/pack_addon.py` → `dist/stalker-pda-addon-0.1.0.zip`.
2. MO2 → «Install a new mod from an archive» → этот zip, включить мод.
3. Запустить GAMMA 0.9.5 через MO2, загрузить сохранение, побегать минуту.
4. Найти снимки:
   `cd bridge && python -m pda_bridge --locate "ПАПКА_ANOMALY" "ПАПКА_MO2"`.
5. Запустить мост командой, которую напечатает `--locate`, открыть
   `http://127.0.0.1:47615`, отсканировать QR на вкладке «Связь» телефоном.

## 2. Прислать результаты

- [ ] `pda_report.txt` (лежит рядом со снимками)
- [ ] все строки `[xpda]` из `appdata\logs\xray_*.log`
- [ ] вывод `--locate`
- [ ] `bridge\.data\bridge.log`
- [ ] что показывает вкладка «Связь» и данные на «Статусе»
- [ ] что пишется в «Статусе» о дне: совпадает ли день с игровым
      (проверка `level.get_time_days()`)
- [ ] есть ли просадка FPS (строка статистики `[xpda] за 60 с: ...` в логе)

## 3. Файлы для следующих этапов

Положить в `vendor/gamma-0.9.5/`, только копии, без правок:

- [ ] `modlist.txt` профиля GAMMA (`GAMMA\profiles\<профиль>\modlist.txt`)
- [ ] скрипты заданий, которые реально выигрывают в MO2: task manager,
      taskboard, динамические задания, FATE (`gamedata\scripts` этих модов)
- [ ] конфиг карт уровней (`game_maps_single.ltx` или его замена в GAMMA)
- [ ] скрипт состояния тела и инвентаря

Без них задания, карта с подложкой и инвентарь не делаются: признаки GAMMA
пришлось бы выдумывать.
