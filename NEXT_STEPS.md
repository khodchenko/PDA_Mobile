# Что нужно сделать владельцу проекта

## 1. Один раз подготовить компьютер

- [ ] Установить Python с https://www.python.org/downloads/ и при установке
      отметить галочку «Add python.exe to PATH».
- [ ] Получить папку проекта на Рабочий стол:
      `C:\Users\khodc_ztb16qt\Desktop\real-pda-mobile`.

## 2. Проверить ПДА без игры

- [ ] Двойной щелчок по `start-demo.bat`. Откроется браузер с ПДА на
      демо-данных.
- [ ] Телефон в той же Wi-Fi сети: вкладка «Связь» → отсканировать QR.
      Если Windows спросит про брандмауэр, разрешить.

## 3. Поставить аддон в игру

- [ ] Двойной щелчок по `pack-addon.bat`. Откроется папка с
      `stalker-pda-addon-0.1.0.zip`.
- [ ] MO2 → «Install a new mod from an archive» → этот zip → включить мод.
- [ ] Запустить GAMMA через MO2, загрузить сохранение, побегать пару минут.

## 4. ПДА с настоящей игрой

- [ ] Не закрывая игру, двойной щелчок по `start-game.bat`. Первый раз он
      спросит папку GAMMA (ту, где лежат папки Anomaly и GAMMA).

## 5. Прислать результаты

- [ ] `pda_report.txt` (путь к нему напишет окно `start-game.bat`)
- [ ] все строки `[xpda]` из `Anomaly\appdata\logs\xray_*.log`
- [ ] текст из окна `start-game.bat`
- [ ] что показывают вкладки «Связь» и «Статус», совпадают ли день, здоровье
      и деньги с игрой
- [ ] есть ли просадка FPS

## 6. Файлы для следующих этапов

Положить в `vendor/gamma-0.9.5/`, только копии, без правок:

- [ ] `modlist.txt` профиля GAMMA (`GAMMA\profiles\<профиль>\modlist.txt`)
- [ ] скрипты заданий, которые реально выигрывают в MO2: task manager,
      taskboard, динамические задания, FATE (`gamedata\scripts` этих модов)
- [ ] конфиг карт уровней (`game_maps_single.ltx` или его замена в GAMMA)
- [ ] скрипт состояния тела и инвентаря

Подробности установки: `README_GAMMA.md`.
