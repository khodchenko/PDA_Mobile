# Совместимость с GAMMA 0.9.5 и Anomaly 1.5.3

Цель: Anomaly 1.5.3 и GAMMA 0.9.5 на движке X-Ray Monolith
MT-TEST_2026.5.5. GAMMA 0.9.6 и текущий `main` не цель.

Состояние на 2026-10-07: экспортёр проверен только вне игры, под LuaJIT 2.1
с заглушками движка (`addon/tests/harness.lua`). В GAMMA и в чистой Anomaly
не запускался.

## Принцип

Исходников GAMMA 0.9.5 в репозитории нет, поэтому GAMMA-специфичных вызовов
нет. Используется только общий скриптовый API Anomaly, на котором работают
обычные аддоны. Каждый вызов обёрнут в `pcall`: если его нет в сборке, поле
пропадает из снимка, а в лог один раз пишется `поле ... не читается` с
ошибкой движка. Нулями ничего не подменяется. `pda_report.txt` на первом
кадре показывает, что реально прочиталось.

## Что вызывает экспортёр

| Поле снимка | Вызов | Если вызова нет |
| --- | --- | --- |
| запуск | `on_game_start`, `RegisterScriptCallback` для `actor_on_first_update`, `actor_on_update`, `actor_on_net_destroy` | аддон не стартует, строк `[xpda]` в логе нет |
| время для расписания | `time_global()` | экспорт не стартует, ошибка в логе |
| папка | `getFS():update_path("$app_data_root$", "")`, затем `"$game_saves$"`, или `snapshot_dir` из конфига | следующая папка по списку |
| настройки | `ini_file("xpda.ltx")`, `section_exist`, `line_exist`, `r_string` | настройки по умолчанию |
| запись | `io.open(path, "wb")` | следующая папка; 50 ошибок подряд — экспорт выключается до загрузки |
| `level.id` | `level.name()` | нет блока `level` |
| `level.name` | `game.translate_string(id)` | нет названия, только id |
| `position` | `db.actor:position()` | нет позиции |
| `heading_deg` | `device().cam_dir` | нет направления |
| `game_time` | `level.get_time_days()`, `get_time_hours()`, `get_time_minutes()` | нет времени |
| `health` | `db.actor.health` | нет здоровья |
| `radiation` | `db.actor.radiation` | нет радиации |
| `game_state = dead` | `db.actor:alive()` | смерть определяется по `health = 0` |
| `player.name` | `db.actor:character_name()` | нет имени |
| `player.id` | `db.actor:id()` | нет id |
| `player.money` | `db.actor:money()` | нет денег |
| сессия | `os.time()` (если есть), `math.random` | только `time_global` и `math.random` |
| замер стоимости | `os.clock()` | статистика без миллисекунд |
| страница MCM | `on_mcm_load` в `xpda_mcm.script`, тип `desc`, `ui_hook_functor` | пункта меню нет, экспортёр работает как раньше |
| статус моста | `io.open` файла `pda_bridge.txt`, `os.time` для давности | строка «мост не запущен» или статус без секунд |

Что из этого надо подтвердить на первом запуске:

- `level.get_time_days()`: это номер дня с начала игры или день месяца.
  Схема требует `day >= 1`. Если значение вне диапазона, поле отбрасывается
  с причиной в логе.
- Кодировка строк. Русская локализация отдаёт cp1251, режим `auto` его
  перекодирует. Для других языков может понадобиться `text_encoding`.
- Есть ли в сборке `os.time` и `os.clock`. Оба необязательны.

## Ограничения движка, которые учтены

| Ограничение Monolith | Как обходим |
| --- | --- |
| Сокеты Lua только при `lua_debug` | Игра пишет файлы, мост читает. Порт в игре не открывается |
| Нет `os.rename` | Нет атомарной замены. Файл обрамлён `seq` … `seq_end`, мост отбрасывает недописанное |
| Нет `os.execute`, `os.remove`, `io.popen` | Не используются. Папки не создаются, файлы не удаляются |
| Лог и консоль в cp1251 | Строки лога перекодируются из UTF-8 перед `printf` |
| MO2 VFS | Мост читает снимки снаружи. `--locate` находит их в `overwrite` |

## Что не GAMMA-специфично и почему

`reader` в снимке всегда `anomaly`. GAMMA сейчас не определяется: правило
плана — выбирать читатель по тому, какие скрипты и глобалы реально загружены
в сессии. Без скриптов 0.9.5 список признаков был бы выдуман.

Для заданий, контактов, инвентаря и карты нужны файлы установки, в
`vendor/gamma-0.9.5/`, только для чтения:

| Что | Какой файл | Где обычно лежит | Зачем |
| --- | --- | --- | --- |
| Список модов | `modlist.txt` профиля | `GAMMA\profiles\<профиль>\modlist.txt` | Какие моды реально включены и чьи файлы выигрывают |
| Задания | task manager, taskboard, динамические задания, FATE | `gamedata\scripts` выигравших модов | Читатель `gamma` для заданий |
| Карта | `game_maps_single.ltx` или его замена в GAMMA | `gamedata\configs` | Границы уровня и текстура для подложки |
| Инвентарь | скрипт состояния тела и инвентаря | `gamedata\scripts` | Конечности, вес, список предметов |

## Как проверяется здесь

```bash
python3 addon/tests/test_exporter.py   # сценарии экспортёра + парсер моста
cd web && npm test                     # снимки экспортёра по JSON Schema (ajv)
```

Сценарии: обычная сессия со сменой уровня и смертью, сломанное API
(нет денег, имени, камеры, радиации), недоступный appdata, папка из
конфига, строки в UTF-8, игровое время вне диапазона.

Не проверяется здесь: запуск GAMMA, загрузка сохранения, обычный ПДА игры,
FPS, настоящий путь записи под MO2.
