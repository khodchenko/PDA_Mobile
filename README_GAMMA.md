# Установка внешнего ПДА в GAMMA 0.9.5

Подходит и для чистой Anomaly 1.5.3 через MO2. Аддон только добавляет три
новых скрипта и один конфиг. Файлы GAMMA не перезаписываются, сохранение не
трогается. Удаляется снятием галочки в MO2.

Состояние: экспортёр проверен на заглушках движка под LuaJIT. **В настоящей
игре ещё не запускался.** Первый запуск у вас и есть проверка канала (пункт 0
плана). Что прислать, если что-то не так, — в конце.

## 1. Собрать аддон

```bash
python3 tools/pack_addon.py
```

Получится `dist/stalker-pda-addon-0.1.1.zip`. Внутри только `gamedata/`:

```
gamedata/scripts/xpda_export.script   экспортёр
gamedata/scripts/xpda_json.script     JSON-кодировщик
gamedata/scripts/xpda_text.script     перекодировка cp1251 → UTF-8
gamedata/scripts/xpda_mcm.script      страница MCM со статусом моста
gamedata/configs/xpda.ltx             настройки
gamedata/configs/text/rus|eng/ui_mcm_xpda.xml
```

## 2. Поставить в MO2

1. MO2 → «Install a new mod from an archive» → выбрать zip. Имя, например,
   `Stalker PDA export`.
2. Включить мод. Место в списке не важно: имена файлов уникальные (`xpda_*`),
   ни с чем в GAMMA не пересекаются.
3. Профиль GAMMA, запуск через MO2 как обычно.

## 3. Первый запуск

1. Загрузить сохранение или начать новую игру.
2. В консоли (`~`) или в `appdata\logs\xray_*.log` появятся строки `[xpda]`:

   ```
   [xpda] экспортёр 0.1.1 загружен
   [xpda] папка ...\appdata\ ($app_data_root$): запись работает
   [xpda] экспорт 0.1.1 запущен: сессия ..., папка ...
   ```

3. Рядом со снимками появится `pda_report.txt`: какая папка выбрана, какие
   функции Lua есть в этой сборке, какие поля прочитались на первом кадре.
4. Раз в минуту в лог пишется статистика: сколько снимков записано и сколько
   миллисекунд это стоило Lua.
5. В игре: Esc → Настройки модов (MCM) → «Внешний ПДА». Настроек там нет.
   Страница показывает, что игра видит мод, идёт ли экспорт и жив ли мост
   на ПК. Мост пишет это в `pda_bridge.txt` рядом со снимками. Если мост не
   запущен, на странице так и написано.

## 4. Найти папку снимков и запустить мост

Под MO2 новые файлы игры обычно оказываются не в папке игры, а в
`overwrite` профиля MO2. Мост найдёт их сам.

По инструкции установки это две разные папки в корне одного диска, не одна
внутри другой: `C:\Anomaly` и `C:\GAMMA` (или `D:\Anomaly` и `D:\GAMMA`).

```bash
cd bridge
python -m pda_bridge --locate "C:\Anomaly" "C:\GAMMA"
```

`start-game.bat` делает то же самое: если указать только `C:\GAMMA`, мост
сам посмотрит и в `C:\Anomaly`. Он напечатает готовую команду, например:

```bash
python -m pda_bridge --snapshot-dir "C:\GAMMA\profiles\GAMMA\overwrite\appdata"
```

Дальше как в `README.md`: открыть `http://127.0.0.1:47615` на ПК, на вкладке
«Связь» отсканировать QR телефоном.

Чтобы путь был всегда один и тот же, создайте папку, например
`C:\stalker_pda`, и укажите её в `gamedata\configs\xpda.ltx` (правка внутри
папки мода в MO2):

```ini
snapshot_dir = C:\stalker_pda
```

Игра не умеет создавать папки, поэтому папка должна уже существовать.

## Что показывает телефон

Уровень и его название, координаты, направление взгляда, игровое время,
здоровье, радиация, имя персонажа и деньги. Вкладка «Связь» показывает, на
каком участке игра → аддон → мост → телефон оборвалась связь.

Задания, инвентарь, контакты и сообщения пока не передаются, телефон пишет
«недоступно». Почему — в `GAMMA_COMPATIBILITY.md`.

## Удаление

Снять галочку с мода в MO2. Можно удалить `pda_fast.json`, `pda_slow.json`,
`pda_report.txt` из папки снимков. В сохранении от аддона ничего не остаётся.

## Если не работает, пришлите

1. `pda_report.txt`.
2. Все строки `[xpda]` из `appdata\logs\xray_*.log` (лог последнего запуска).
3. `bridge\.data\bridge.log`.
4. Что видно на вкладке «Связь»: какой шаг красный и что под ним написано.

Частые случаи:

| Что видно | Где смотреть |
| --- | --- |
| В логе нет ни одной строки `[xpda]` | Мод не включён в MO2 или игра запущена не через MO2 |
| `ни одна папка не подошла для записи` | Указать существующую папку в `snapshot_dir` |
| `поле ... не читается` | Нормально для отдельных полей: поле не придёт на телефон. Пришлите строку, разберём |
| Мост: `в ... пока нет снимков` | Запустить `--locate`, папка, скорее всего, в `overwrite` |
| Телефон: «Мост не отвечает» | Брандмауэр Windows, порт TCP 47615, одна Wi-Fi сеть |
